Mochi test client

Stands in for the Pi bridge: joins the Agora channel as the Pi (uid from the device state) and sends your voice or a recorded clip. Development tool only.

Wear headphones. Speakers would play Mochi's voice back into the mic as a new turn.

Start the session first: curl -X POST <backend>/api/sessions/demo/start. Stop it after each run (it uses free Agora minutes).
